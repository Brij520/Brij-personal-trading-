# 02 · Reading a research report

The report is 25 sections. You should not read them in order, and you should not read all of
them. Read in this order.

## 1. Header: provenance first (10 seconds)
Source, freshness, verification. If it says **SYNTHETIC**, you are reading a demonstration of
the software, not a fact about a company. Stop and switch to real data before drawing any
conclusion. If it says `DELAYED`, note by how much.

## 2. The verdict and the cheapest rejection (30 seconds)
**Final research classification** + **Thesis invalidation**. Ask one question: *what would make
this wrong?* If the invalidation is vague ("if the market falls"), the report is not finished.
Then read the reasons for the classification — the committee lists them in order.

`NO TRADE` and `INSUFFICIENT DATA` are outcomes, not failures. The single most expensive
mistake with a research tool is treating a non-answer as a weak yes.

## 3. Data limitations (1 minute)
Read this before any numbers. Which statements were unavailable? How many bars of history?
Is the news set three items long? Every quantitative claim below is conditional on these
limits, and the limits are usually more informative than the metrics.

## 4. The debate (2 minutes)
Bull case, then bear case. You are looking for one thing: **does the bear case engage with the
bull's strongest point, or does it attack a straw man?** If the two sections talk past each
other, the evidence is thin and the classification will be `WATCHLIST` anyway.

## 5. Valuation, but only the assumptions (2 minutes)
Read WACC build-up, growth path, terminal growth, net debt. Skip the output value. The output
is arithmetic; the assumptions are the analysis. If terminal growth is above nominal GDP growth
forever, the model is wrong regardless of the number it printed.

For banks/NBFCs, the method should be justified P/B — a DCF on a lender is fiction, and the
report says which method it used and why.

## 6. Risk section (1 minute)
Sizing, heat, veto reasons. If risk rejected the idea, the report is already answered.

## What to ignore

- **The overall score.** It is an aggregate of ordinal judgments and is not a probability of
  profit. It exists for sorting, nothing else.
- **Any language resembling a target price.** There isn't one, deliberately. The intrinsic
  range is an input to your thinking, not an instruction.
- **Agent agreement.** Two agents agreeing on the same data are one piece of evidence. The
  committee counts independent evidence types, and so should you.

## The test

After reading, you should be able to state, in two sentences, the thesis and what kills it.
If you cannot, you have read a document, not done research.
